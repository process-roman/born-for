# Living-sky terrain

`life-mountains.webp` is a transparent illustrated foreground generated for Born For, encoded as WebP with alpha. It contains only mountains, atmospheric distance and the central path. The sky, moving sun, mastery stars, joy light, element tint, evening shade and low-energy mist are rendered separately by `LifeSky.tsx`.

The artwork remains inside the existing arch and does not determine game state or scene dimensions. It is bundled locally; no external image service is needed.
